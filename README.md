# instagram-panorama-splitter
simple python script with small user interface to split a 9:4 panorama jpeg into 3 equal jpegs for use e.g. for instagram

Details

A simple Python tool for Windows that splits a panorama into three equally sized images for Instagram.
Requirements:

    Windows 10 or 11

    Python 3

    Pillow (this is a Python library for image processing and editing)

Installation "Pillow" as pre-requisite within powershell:
    python -m pip install -r requirements.txt


Use:
    1. Start the script.
    2. Select a panoramic photo (must already have a ratio of 9x4)
    3. Click "Split".

The three images will be saved in the "Export" sub-folder.
